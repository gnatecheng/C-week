常见问题

如何安装 C一周通 APK？

在 GitHub Releases 下载最新 APK 并安装。桌面显示「C一周通」。

系统要求是什么？

最低 Android 8.0（API 26）；内含 H.264 教学视频，较新系统通常播放更稳定。

需要联网吗？

课文、演示视频与实验数据打包在 APK 内；学习进度等存在 DataStore，日常学习不需要联网。

C一周通会在手机上编译 C 吗？

不会。C一周通使用离线模拟评测（多组用例 + 规则检查 + 错因提示），部分通过会显示分数，全部通过才记实验完成；手机端无需安装 gcc。

C一周通和电脑上的 VS Code 怎么配合？

可在 PC/Mac/Linux 安装 VS Code 与 gcc，打开 c-week 仓库，对照 app/src/main/assets/labs/ 中的 .c 文件跟做；Day 7 参考 day7_dijkstra.c，期望输出示例见该仓库 README。
