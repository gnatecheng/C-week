7 天学习路线

7 天路线与应用内课程一致；每天含微课、测验与实验。

D1

环境、文件与 Hello World

路径 · bash · VS Code · 第一次编译

能分清路径与工作区，用终端做基本文件操作，在 VS Code 里新建 .c、用 gcc 编译运行，并看懂 launch.json 与断点调试。

实验：输出 Hello, Ada
D2

类型、变量与 I/O

静态类型 · printf/scanf · 没有自动回收

能声明 int/double/char，用 printf/scanf 读写，理解溢出与栈上变量生命周期。

实验：摄氏 ↔ 华氏
D3

控制流与函数

if/for/while · 原型 · 传值

能写带原型的函数，理解 C 传值；知道为什么 swap 必须用指针（为 Day 4 铺路）。

实验：写一个 is_prime
D4

数组、字符串、指针

连续内存 · 地址 · '\0'

能画指针图，正确用数组与 '\0' 字符串，避开越界和数组退化陷阱。

实验：原地反转字符串
D5

结构体、堆内存、文件

struct · malloc/free · fopen

能定义 struct、在堆上分配邻接表节点、正确 free，并做基础文件读写。

实验：结构体数组求最高分
D6

算法热身：排序与 BFS

选择排序 · 邻接表 · 网格/图 BFS

理解选择排序、用数组模拟邻接表，并完成 BFS（队列 + dist[]）。

实验：补全 BFS 松弛
D7

大作业：Dijkstra 最短路

正权图 · 邻接表 · O(V²) 教学实现

独立补全松弛循环，能解释与 BFS 的差别，并在 VS Code 里编译运行测试。

大作业：补全 Dijkstra 松弛

常见问题

如何安装 C一周通 APK？

在 GitHub Releases 下载最新 APK 并安装。桌面显示「C一周通」。

安装提示（Android 版本、未知来源、覆盖安装）

C一周通需要 Android 8.0 及以上。请从 GitHub Releases 下载正式签名版 APK 安装。首次安装时，系统可能提示「不允许安装未知应用」——请在设置里为浏览器或文件管理器开启「允许安装未知来源应用」（各品牌路径与 wording 不同）。若提示签名冲突，需先卸载旧版再装新版；卸载会删除学习进度等本机数据，如有导出功能请先备份。

系统要求是什么？

Android 8.0 及以上；内含打包教学视频。当前正式版 v1.5.1，安装包约 15.6 MB（以 GitHub Releases 为准）。

需要联网吗？

课文、演示视频与实验内容都打包在安装包内；学习进度保存在本机，日常学习不需要联网。

C一周通会在手机上编译 C 吗？

不会。C一周通使用离线模拟评测（多组用例 + 规则检查 + 错因提示），部分通过会显示分数，全部通过才记实验完成；手机端无需安装 gcc。

C一周通和电脑上的 VS Code 怎么配合？

可在电脑上安装 VS Code 与 C 语言编译环境，打开 C一周通开源仓库 跟练第 7 天大作业等示例；应用内 About 页也有项目链接。
