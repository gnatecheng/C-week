7 天学习路线

课程地图与 `app/src/main/assets/curriculum/map.json` 及 Kotlin 课文一致；每天含微课、测验与实验。

D1

环境、文件与 Hello World

路径 · bash · VS Code · 第一次编译

能分清路径与工作区，用终端做基本文件操作，在 VS Code 里新建 .c、用 gcc 编译运行，并看懂 launch.json 与断点调试。

实验：输出 Hello, Ada
D2

类型、变量与 I/O

静态类型 · printf/scanf · 没有自动回收

能声明 int/double/char，用 printf/scanf 读写，理解溢出与栈上变量生命周期。

实验：摄氏 ↔ 华氏
D3

控制流与函数

if/for/while · 原型 · 传值

能写带原型的函数，理解 C 传值；知道为什么 swap 必须用指针（为 Day 4 铺路）。

实验：写一个 is_prime
D4

数组、字符串、指针

连续内存 · 地址 · '\0'

能画指针图，正确用数组与 '\0' 字符串，避开越界和数组退化陷阱。

实验：原地反转字符串
D5

结构体、堆内存、文件

struct · malloc/free · fopen

能定义 struct、在堆上分配邻接表节点、正确 free，并做基础文件读写。

实验：结构体数组求最高分
D6

算法热身：排序与 BFS

选择排序 · 邻接表 · 网格/图 BFS

理解选择排序、用数组模拟邻接表，并完成 BFS（队列 + dist[]）。

实验：补全 BFS 松弛
D7

大作业：Dijkstra 最短路

正权图 · 邻接表 · O(V²) 教学实现

独立补全松弛循环，能解释与 BFS 的差别，并在 VS Code 里编译运行测试。

大作业：补全 Dijkstra 松弛

轻记账

个人记账 Android 应用。数据保存在手机上的 SQLite（Room）里，无需登录、无需服务器；没有账号系统，也没有网络同步，备份文件只有你分享或保存时才会离开本机。

主要功能

流水

记一笔 · 搜索筛选

金额、日期时间、收支、分类、账户、备注、标签；快速记一笔、按月切换；备注/标签全文搜索，可按分类、账户、标签、金额区间、收支/转账类型筛选。

转账

账户之间互转

转出/转入、金额、日期、备注；两端余额同步更新；不计入月度收入/支出，明细中以独立样式展示。

分类 · 账户

分类与账户

支出/收入两套分类，可编辑名称与颜色，首次启动带中文默认分类；现金、银行卡、信用卡、支付宝、微信等账户，余额随流水更新。

统计

月度统计与趋势

月度收支与结余（对比上月）、分类饼图、近 12 个月趋势；可按时间、账户、标签筛选，可分享月报图片或导出 PDF。

预算

预算与提醒

每月总预算 + 分类预算；达到 80% 警告、超过 100% 超支；可配置大额单笔阈值；多日未记账会在首页轻提醒。

备份

导入导出

导出 CSV 与 JSON 完整备份（流水、分类、账户、预算、提醒设置）；导入可预览、识别常见列名，重复可选跳过 / 全部导入 / 覆盖。

自动

周期记账

每天 / 每周 / 每月规则；打开应用时自动生成到期流水；可编辑、暂停、删除。

小组件

桌面小组件

显示本月收入、支出、结余（绿/红），点按打开应用，记账后自动刷新。

隐私

收据拍照

记账时可拍照或从相册选图，照片只保存在本机，支持缩略图、更换和删除。

另有深色模式开关（我的 / 设置）；首次打开会写入示例流水，可在「我的 → 提醒设置」中清除或恢复。技术栈：Kotlin、Jetpack Compose、Material 3、Room、Navigation Compose。

多人事务

单班事务记录 Android 应用：出勤、缴费、费用分摊、清单。数据保存在本机（Room），无需登录或联网。

主要功能

成员

成员与名单

成员增删改、软归档（学号、备注可选）；批量粘贴导入，支持学号在前、Tab 粘贴，重名/同学号会提示；可恢复已归档成员并保留历史事务。

团体

班内小团体

多选成员组成团体，一人可属于多个团体；事务范围可选全班或某个小团体（空团体不能作为事务范围）。

事务

四种事务

出勤 / 缴费 / 分摊 / 清单；创建时快照成员，之后改团体名单不影响历史；「再开一期」按当前名单重新快照。

分摊

灵活分摊

金额以「分」存储、界面以「元」显示，余数补给前 N 人；可排除同学、按权重或固定金额分摊。

进度

进度与点名

事务详情默认「仅未完成」，点按更新状态；缴费/分摊可编辑金额；出勤事务支持连续点名；名单按学号排序（可关）。

催缴

摘要与催缴文案

复制摘要 / 催缴文案，按微信群可读格式（一人一行、含金额）；详情可复制/分享未完成名单与 CSV。

班费

班费账本

收入/支出流水与余额；缴费事务可将已收合计记入班费；缴费/分摊可附加备注与图片凭证。

备份

备份与导出

数据备份 / 恢复（zip，含缴费凭证图片）；导出成员、事务进度、账本 CSV。

小组件

未完成人数小组件

显示近期进行中事务的未完成人数（多项时附全部合计），点按打开应用。

首页可按标题搜索事务、筛选进行中 / 已归档；新建事务提供点名、班费、寝室分摊等快捷标题模板；Material 3 深色主题可跟随系统或固定浅色 / 深色。技术栈：Kotlin · Jetpack Compose · Material 3 · Navigation Compose · Room · DataStore · App Widget · Flow · Coroutines · MVVM。
