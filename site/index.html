常见问题

如何安装 APK？

在 GitHub Releases 下载最新 APK。Android 需允许「安装未知应用」（因渠道而异）。安装后桌面显示「C一周通」。

系统要求是什么？

最低 Android 8.0（API 26，对应 minSdk 26），目标 SDK 35。建议使用较新系统以获得更好的 Media3 视频播放与 Material 3 体验。

需要联网吗？

不需要。课文、`assets/vscode_demos/*.mp4` 与实验数据均打包在 APK 内；进度、错题本等保存在本机 DataStore，无后端。

实验会在手机上编译 C 吗？

不会。应用使用离线模拟评测（多组用例 + 规则检查 + 中文错因提示），部分通过会显示分数，全部通过才记实验完成。

和电脑上的 VS Code 怎么配合？

可在 PC/Mac/Linux 安装 VS Code 与 gcc，打开本仓库对照 app/src/main/assets/labs/ 中的 .c 文件跟做；Day 7 参考 day7_dijkstra.c，期望输出示例见 README。
