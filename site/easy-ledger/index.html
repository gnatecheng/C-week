完整功能

流水

记一笔 · 搜索筛选

金额、日期时间、收支、分类、账户、备注、标签；快速记一笔、按月切换；备注/标签全文搜索，可按分类、账户、标签、金额区间、收支/转账类型筛选。

转账

账户之间互转

转出/转入、金额、日期、备注；两端余额同步更新；不计入月度收入/支出，明细中以独立样式展示。

分类 · 账户

分类与账户

支出/收入两套分类，可编辑名称与颜色，首次启动带中文默认分类；现金、银行卡、信用卡、支付宝、微信等账户，余额随流水更新。

统计

月度统计与趋势

月度收支与结余（对比上月）、分类饼图、近 12 个月趋势；可按时间、账户、标签筛选，可分享月报图片或导出 PDF。

预算

预算与提醒

每月总预算 + 分类预算；达到 80% 警告、超过 100% 超支；可配置大额单笔阈值；多日未记账会在首页轻提醒。

备份

导入导出

导出 CSV 与 JSON 完整备份（流水、分类、账户、预算、提醒设置）；导入可预览、识别常见列名，重复可选跳过 / 全部导入 / 覆盖。

自动

周期记账

每天 / 每周 / 每月规则；打开应用时自动生成到期流水；可编辑、暂停、删除。

小组件

桌面小组件

显示本月收入、支出、结余（绿/红），点按打开应用，记账后自动刷新。

隐私

收据拍照

记账时可拍照或从相册选图，照片只保存在本机，支持缩略图、更换和删除。

支持浅色 / 深色 / 跟随系统主题（我的 → 设置）。首次打开会写入示例流水，可在「我的 → 提醒设置」中清除或恢复。

隐私与权限

记账流水、分类、账户、预算与提醒设置都保存在本机，无需注册账号，也没有云同步。

记账时可拍照或从相册选择收据，照片只存在您的手机里，可随时更换或删除。

应用未声明联网权限，日常记账不需要联网。备份、恢复或导出 CSV/JSON 只有您主动操作时才会生成文件，并通过系统分享或「另存为」离开本机。

若您曾安装过测试版或旧签名版本，请先卸载再安装当前正式版，否则可能提示签名冲突；卸载会清除应用内数据，请先使用应用内备份。

常见问题

如何安装轻记账 APK？

在 GitHub Releases 下载最新 APK 并安装。Android 需允许「安装未知应用」。桌面显示「轻记账」。

安装提示（Android 版本、未知来源、覆盖安装）

轻记账需要 Android 8.0 及以上。请从 GitHub Releases 下载正式签名版 APK 安装。首次安装时，系统可能提示「不允许安装未知应用」——请在设置里为浏览器或文件管理器开启「允许安装未知来源应用」（各品牌路径与 wording 不同）。若提示签名冲突，需先卸载旧版再装新版；卸载会删除应用内数据，请先使用应用内备份。若曾安装测试版或旧签名版本，请先卸载后再安装当前正式版。

系统要求是什么？

Android 8.0 及以上。当前正式版 v1.3.2，安装包约 13.0 MB（以 GitHub Releases 为准）。

需要联网吗？

日常使用不需要联网；流水与设置都保存在本机，无登录或必需的后端服务。

如何备份数据？

应用内提供数据备份 / 恢复（zip）与 CSV 导出；备份文件只有你主动分享或保存时才会离开本机。
