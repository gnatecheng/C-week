常见问题

如何安装轻记账 APK？

在 GitHub Releases 下载最新 APK 并安装。Android 需允许「安装未知应用」。桌面显示「轻记账」。

系统要求是什么？

最低 Android 8.0（API 26，minSdk 26），目标 SDK 35。详见仓库 app/build.gradle.kts。

需要联网吗？

日常使用不需要联网；流水与设置在 Room（SQLite）中，无登录或必需的后端服务。

如何备份数据？

应用内提供数据备份 / 恢复（zip）与 CSV 导出；备份文件只有你主动分享或保存时才会离开本机。
