团团记

任何小团体（社团、寝室、兴趣小组、球队、家庭/朋友聚会、班级）的点名、收团费、AA 分摊和清单，一个离线 App 记清楚，催缴文案一键发群。

完整功能

成员

成员与名单

成员增删改、软归档（编号、备注可选）；批量粘贴导入，支持编号在前、Tab 粘贴，重名/同编号会提示；可恢复已归档成员并保留历史事务。

团体

团内小团体

多选成员组成小团体，一人可属于多个小团体；事务范围可选全团或某个小团体（空团体不能作为事务范围）。

事务

四种事务

出勤 / 缴费 / 分摊 / 清单；范围可选全团或某个小团体；创建时快照成员，之后改团体名单不影响历史；「再开一期」按当前名单重新快照。

分摊

灵活分摊

金额以「分」存储、界面以「元」显示，余数补给前 N 人；可排除成员、按权重或固定金额分摊。

进度

进度与点名

事务详情默认「仅未完成」，点按更新状态；缴费/分摊可编辑金额；出勤事务支持连续点名；名单按编号排序（可关）。

催缴

摘要与催缴文案

复制摘要 / 催缴文案，按微信群可读格式（一人一行、含金额）；详情可复制/分享未完成名单与 CSV。

团费

团费账本

收入/支出流水与余额；缴费事务可将已收合计记入团费；缴费/分摊可附加备注与图片凭证。

备份

备份与导出

数据备份 / 恢复（zip，含缴费凭证图片）；导出成员、事务进度、账本 CSV。

小组件

未完成人数小组件

显示近期进行中事务的未完成人数（多项时附全部合计），点按打开应用。

首页可按标题搜索事务、筛选进行中 / 已归档；新建事务与再开一期提供点名、团费、分摊等快捷标题模板；主题可跟随系统或固定浅色 / 深色（设置中切换）。

隐私与权限

团体、成员与事务记录都保存在本机，无需注册账号，也没有云端服务器。

备份文件为 zip，可包含缴费凭证照片；只有您主动导出或恢复时才会离开手机。

应用未声明联网权限，日常记录不需要联网。通常只需组织者在手机上安装；成员不必安装 App。

常见问题

如何安装团团记 APK？

在 GitHub Releases 下载最新 APK 并安装。桌面显示「团团记」。

安装提示（Android 版本、未知来源、覆盖安装）

团团记需要 Android 8.0 及以上。请从 GitHub Releases 下载正式签名版 APK 安装。首次安装时，系统可能提示「不允许安装未知应用」——请在设置里为浏览器或文件管理器开启「允许安装未知来源应用」（各品牌路径与 wording 不同）。若提示签名冲突，需先卸载旧版再装新版；卸载会删除应用内数据，请先使用应用内 zip 备份。若曾安装测试版或旧签名版本，请先卸载后再安装当前正式版。

系统要求是什么？

Android 8.0 及以上。当前正式版 v1.5.2，安装包约 13.1 MB（以 GitHub Releases 为准）。

需要联网吗？

团体与事务数据保存在本机；应用未声明联网权限，日常使用不需要联网，也无登录或后端服务。

谁需要安装 App？

目前只有 Android 版，且通常由组织者在一台手机上维护团体与事务；成员不用安装 App，点名/缴费状态由组织者在应用内更新。

能否多人同步或协同编辑？

不能。团团记是单机离线应用，没有账号、服务器或多设备同步；如需换机请使用应用内的 zip 备份 / 恢复。
