Etai Apps: three offline Android apps — data stays on your device

轻记账

个人记账 Android 应用。数据保存在手机上的 SQLite（Room）里，无需登录、无需服务器；没有账号系统，也没有网络同步，备份文件只有你分享或保存时才会离开本机。

主要功能

流水

记一笔 · 搜索筛选

金额、日期时间、收支、分类、账户、备注、标签；快速记一笔、按月切换；备注/标签全文搜索，可按分类、账户、标签、金额区间、收支/转账类型筛选。

转账

账户之间互转

转出/转入、金额、日期、备注；两端余额同步更新；不计入月度收入/支出，明细中以独立样式展示。

分类 · 账户

分类与账户

支出/收入两套分类，可编辑名称与颜色，首次启动带中文默认分类；现金、银行卡、信用卡、支付宝、微信等账户，余额随流水更新。

统计

月度统计与趋势

月度收支与结余（对比上月）、分类饼图、近 12 个月趋势；可按时间、账户、标签筛选，可分享月报图片或导出 PDF。

预算

预算与提醒

每月总预算 + 分类预算；达到 80% 警告、超过 100% 超支；可配置大额单笔阈值；多日未记账会在首页轻提醒。

备份

导入导出

导出 CSV 与 JSON 完整备份（流水、分类、账户、预算、提醒设置）；导入可预览、识别常见列名，重复可选跳过 / 全部导入 / 覆盖。

自动

周期记账

每天 / 每周 / 每月规则；打开应用时自动生成到期流水；可编辑、暂停、删除。

小组件

桌面小组件

显示本月收入、支出、结余（绿/红），点按打开应用，记账后自动刷新。

隐私

收据拍照

记账时可拍照或从相册选图，照片只保存在本机，支持缩略图、更换和删除。

另有深色模式开关（我的 / 设置）；首次打开会写入示例流水，可在「我的 → 提醒设置」中清除或恢复。技术栈：Kotlin、Jetpack Compose、Material 3、Room、Navigation Compose。

团团记

面向任意小团体的 Android 事务记录应用：出勤、缴费、费用分摊、清单（社团、宿舍、小组等）。数据保存在本机（Room），无需登录或联网。

主要功能

成员

成员与名单

成员增删改、软归档（编号、备注可选）；批量粘贴导入，支持编号在前、Tab 粘贴，重名/同编号会提示；可恢复已归档成员并保留历史事务。

团体

团内小团体

多选成员组成小团体，一人可属于多个小团体；事务范围可选全团或某个小团体（空团体不能作为事务范围）。

事务

四种事务

出勤 / 缴费 / 分摊 / 清单；范围可选全团或某个小团体；创建时快照成员，之后改团体名单不影响历史；「再开一期」按当前名单重新快照。

分摊

灵活分摊

金额以「分」存储、界面以「元」显示，余数补给前 N 人；可排除成员、按权重或固定金额分摊。

进度

进度与点名

事务详情默认「仅未完成」，点按更新状态；缴费/分摊可编辑金额；出勤事务支持连续点名；名单按编号排序（可关）。

催缴

摘要与催缴文案

复制摘要 / 催缴文案，按微信群可读格式（一人一行、含金额）；详情可复制/分享未完成名单与 CSV。

团费

团费账本

收入/支出流水与余额；缴费事务可将已收合计记入团费；缴费/分摊可附加备注与图片凭证。

备份

备份与导出

数据备份 / 恢复（zip，含缴费凭证图片）；导出成员、事务进度、账本 CSV。

小组件

未完成人数小组件

显示近期进行中事务的未完成人数（多项时附全部合计），点按打开应用。

首页可按标题搜索事务、筛选进行中 / 已归档；新建事务与再开一期提供点名、团费、寝室分摊等快捷标题模板；Material 3 深色主题可跟随系统或固定浅色 / 深色。技术栈：Kotlin · Jetpack Compose · Material 3 · Navigation Compose · Room · DataStore · App Widget · Flow · Coroutines · MVVM。

常见问题

安装、系统要求与离线使用 — 适用于本页三款应用。

How do I install the APK?

Download the latest APK from each app’s GitHub Releases and install: Easy Ledger, Group Matters, and C Week. Android may ask you to allow installs from unknown sources (varies by OEM). Launcher names are “Easy Ledger”, “Group Matters”, and “C Week”.

Install tips (Android version, unknown sources, upgrades)

All three apps use minSdk 26 (Android 8.0)—the same value in each repo’s app/build.gradle.kts (easy-ledger, group-matters, c-week). On first install, Android may block APKs until you allow Install unknown apps for your browser or file manager (wording and location vary by device). If an upgrade fails with a signature conflict, uninstall the old build before installing the new one—uninstalling erases on-device app data, so export or back up first (backup files for Easy Ledger / Group Matters, and any export path for C Week progress).

What are the system requirements?

All three apps require at least Android 8.0 (API 26, minSdk 26) and target SDK 35 (compileSdk 35). C Week bundles H.264 lesson videos; a recent OS version usually plays them more reliably.

Do I need the internet?

No for everyday use—data stays on your device. C Week ships lessons, demo videos, and lab data in the APK; progress lives in DataStore. Easy Ledger stores entries and settings in Room (SQLite). Group Matters stores group and activity data in Room. None require login or a mandatory backend.

Does C Week compile C on the phone?

No. C Week uses offline simulated grading (multiple test cases, rule checks, and feedback). Partial credit shows a score; a lab counts complete only when all cases pass. You do not need gcc on the phone.

How does C Week work with VS Code on a computer?

Install VS Code and gcc on PC/Mac/Linux, open the c-week repo, and follow the .c files under app/src/main/assets/labs/; for Day 7 see day7_dijkstra.c and expected output in that repo’s README.
