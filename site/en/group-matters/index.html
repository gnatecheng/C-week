Group Matters

Roll call, group-fund collection, cost splits, and checklists for any small group—one offline app, reminder text ready to paste into group chat.

  • Copy summary / reminder text in WeChat-friendly format
  • Splits: exclude members, weights, or fixed amounts; cents storage with remainder to first N people
  • Group fund ledger with photo receipts and CSV export
  • Sub-groups; member snapshot when an activity is created
  • Data stays on phone; APK has no network permission; members need not install the app
  • Home-screen widget, zip backup, Chinese & English UI

FAQ

How do I install Group Matters?

Download the latest APK from GitHub Releases and install. Launcher name: “Group Matters” (团团记).

Do I need the internet?

Group and activity data live in Room on device; the APK has no network permission—no login or backend for daily use.

Who needs to install the app?

Android only, usually on one organizer phone; members do not need the app—status is updated by the organizer in the app.

Can multiple people sync or edit together?

No. Group Matters is single-device offline software—no accounts, server, or multi-device sync. Use zip backup / restore to move to a new phone.
