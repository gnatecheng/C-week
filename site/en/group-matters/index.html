Full features

Members

Members and roster

Add/edit/archive members (optional member ID and notes); bulk paste import with ID-first Tab columns, warnings on duplicate names/IDs; restore archived members while keeping history.

Groups

Sub-groups

Multi-select members into sub-groups; one person can join several; activity scope is the whole group or a sub-group (empty groups cannot be selected).

Activities

Four activity types

Attendance / payment / split / checklist; scope is whole group or a sub-group; member snapshot at creation—later roster changes do not alter history; “Start another round” re-snapshots the current roster.

Split

Flexible splits

Amounts stored in cents, shown as ¥ in the English UI; remainder to first N people; exclude members, weight-based or fixed-amount splits.

Progress

Progress and roll call

Activity detail defaults to incomplete-only; tap to update status; edit amounts on payments/splits; continuous roll call for attendance; sort roster by member ID (optional).

Reminders

Summaries and reminder text

Copy summary / reminder text in WeChat-friendly format (one person per line with amounts); share or copy incomplete lists and CSV from details.

Fund

Group fund ledger

Income/expense ledger and balance; payment activities can post collected totals to the group fund; notes and photo receipts on payments/splits.

Backup

Backup and export

Backup/restore data (zip, includes payment receipt images); export members, activity progress, and ledger CSV.

Widget

Incomplete-count widget

Shows incomplete counts for recent in-progress activities (total when several); tap opens the app.

Search activities by title on home; filter in progress / archived; quick title templates for roll call, group fund, and splits when creating activities or starting another round; theme follows system or fixed light/dark in Settings.

All screenshots

Same slides as the carousel above; updates when you switch site language or light / dark / system theme.

Privacy & permissions

Groups, members, and activities stay on your phone—no account and no cloud server.

Backup files are zip archives and can include payment receipt photos; they leave the phone only when you export or restore.

The app does not request the Internet permission—everyday use is offline. Usually only the organizer installs the app; members do not need it.

System requirements

Android 8.0 or newer.

Current release: Group Matters v1.5.2, about 13.1 MB (see GitHub Releases for the exact file size).

FAQ

How do I install Group Matters?

Download the latest APK from GitHub Releases and install. Launcher name: “Group Matters” (团团记).

Install tips (Android version, unknown sources, upgrades)

All three apps require Android 8.0 or newer. Download the signed release APK from each app’s GitHub Releases page. On first install, Android may block APKs until you allow Install unknown apps for your browser or file manager (wording varies by device). If you see a signature conflict, uninstall the old build before installing the new one—uninstalling erases on-device app data, so back up first (in-app backup for Easy Ledger / Group Matters; export progress in C Week if available). For Easy Ledger and Group Matters, if you previously installed a test build or an APK signed with an older key, uninstall it before installing the current signed release.

What are the system requirements?

All three apps support Android 8.0 or newer. C Week bundles lesson videos; a recent phone usually plays them more reliably.

Do I need the internet?

Group and activity data stay on your phone; the app does not request the Internet permission—no login or backend for daily use.

Who needs to install the app?

Android only, usually on one organizer phone; members do not need the app—status is updated by the organizer in the app.

Can multiple people sync or edit together?

No. Group Matters is single-device offline software—no accounts, server, or multi-device sync. Use zip backup / restore to move to a new phone.
