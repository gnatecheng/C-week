Full features

Entries

Quick entry · search and filter

Amount, date/time, type, category, account, note, tags; quick add and month switch; full-text search on notes/tags; filter by category, account, tag, amount range, income/expense/transfer.

Transfer

Account transfers

From/to accounts, amount, date, note; both balances update; excluded from monthly income/expense and shown separately in the list.

Categories · Accounts

Categories and accounts

Separate expense/income categories with editable names and colors; default Chinese categories on first launch; cash, cards, Alipay, WeChat, etc., balances follow transactions.

Stats

Monthly stats and trends

Monthly income, spending, balance (vs last month), category pie, 12-month trend; filter by time, account, tag; share a monthly image or export PDF.

Budget

Budgets and reminders

Monthly total plus per-category budgets; 80% warning and 100% overspend; configurable large-transaction threshold; gentle nudge on the home screen after days without entries.

Backup

Import and export

Export CSV and full JSON backup (entries, categories, accounts, budgets, reminder settings); import with preview, common column detection, duplicates: skip / import all / overwrite.

Auto

Recurring entries

Daily / weekly / monthly rules; creates due entries when you open the app; edit, pause, or delete rules.

Widget

Home screen widget

Shows monthly income, spending, balance (green/red); tap opens the app; refreshes after you log transactions.

Privacy

Receipt photos

Attach a camera shot or gallery image when logging; photos stay on device with thumbnail, replace, and delete.

Dark mode toggle under Me / Settings; first launch seeds sample entries—clear or restore under Me → Reminder settings. Stack: Kotlin, Jetpack Compose, Material 3, Room, Navigation Compose.

All screenshots

English UI, light theme (same slides as the homepage carousel; dark sets load when your theme is dark).

Privacy & permissions

Transactions, categories, accounts, budgets, and reminder settings live in on-device SQLite (Room)—no account or cloud sync. Receipt photos stay in device storage until you capture or pick them.

The README describes a local-first app; everyday budgeting does not require network access. Backup / restore and CSV / JSON export only leave the device when you share or save files.

System requirements

Minimum Android 8.0 (API 26, minSdk 26), compileSdk / targetSdk 35 (see app/build.gradle.kts). Release APK size varies—check the asset on GitHub Releases.

Signed release APKs are built in GitHub Actions when signing secrets are configured; local release builds without secrets may be unsigned—use Releases for sideloading.

FAQ

How do I install Easy Ledger?

Download the latest APK from GitHub Releases and install. Android may ask you to allow installs from unknown sources. Launcher name: “Easy Ledger”.

Install tips (Android version, unknown sources, upgrades)

All three apps use minSdk 26 (Android 8.0)—the same value in each repo’s app/build.gradle.kts (easy-ledger, group-matters, c-week). On first install, Android may block APKs until you allow Install unknown apps for your browser or file manager (wording and location vary by device). If an upgrade fails with a signature conflict, uninstall the old build before installing the new one—uninstalling erases on-device app data, so export or back up first (backup files for Easy Ledger / Group Matters, and any export path for C Week progress).

What are the system requirements?

Minimum Android 8.0 (API 26, minSdk 26), target SDK 35—see app/build.gradle.kts in the repo.

Do I need the internet?

No internet needed for everyday use; entries and settings live in Room (SQLite) with no login or required backend.

How do I back up data?

In-app backup / restore (zip) and CSV export; backup files leave your device only when you share or save them.
