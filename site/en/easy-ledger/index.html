Full features

Entries

Quick entry · search and filter

Amount, date/time, type, category, account, note, tags; quick add and month switch; full-text search on notes/tags; filter by category, account, tag, amount range, income/expense/transfer.

Transfer

Account transfers

From/to accounts, amount, date, note; both balances update; excluded from monthly income/expense and shown separately in the list.

Categories · Accounts

Categories and accounts

Separate expense/income categories with editable names and colors; default Chinese categories on first launch; cash, cards, Alipay, WeChat, etc., balances follow transactions.

Stats

Monthly stats and trends

Monthly income, spending, balance (vs last month), category pie, 12-month trend; filter by time, account, tag; share a monthly image or export PDF.

Budget

Budgets and reminders

Monthly total plus per-category budgets; 80% warning and 100% overspend; configurable large-transaction threshold; gentle nudge on the home screen after days without entries.

Backup

Import and export

Export CSV and full JSON backup (entries, categories, accounts, budgets, reminder settings); import with preview, common column detection, duplicates: skip / import all / overwrite.

Auto

Recurring entries

Daily / weekly / monthly rules; creates due entries when you open the app; edit, pause, or delete rules.

Widget

Home screen widget

Shows monthly income, spending, balance (green/red); tap opens the app; refreshes after you log transactions.

Privacy

Receipt photos

Attach a camera shot or gallery image when logging; photos stay on device with thumbnail, replace, and delete.

Light, dark, or system theme under Me → Settings. First launch adds sample entries—clear or restore under Me → Reminder settings.

All screenshots

Privacy & permissions

Transactions, categories, accounts, budgets, and reminders stay on your phone—no sign-up and no cloud sync.

When you log spending, you can attach a receipt photo from the camera or gallery; photos stay on the device and can be replaced or deleted.

The app does not request the Internet permission—everyday budgeting works offline. Backup, restore, and CSV/JSON export only create files when you choose to, and they leave the phone only if you share or save them.

FAQ

How do I install Easy Ledger?

Download the latest APK from GitHub Releases and install. Android may ask you to allow installs from unknown sources. Launcher name: “Easy Ledger”.

Install tips (Android version, unknown sources, upgrades)

Easy Ledger requires Android 8.0 or newer. Download the signed release APK from GitHub Releases. On first install, Android may block APKs until you allow Install unknown apps for your browser or file manager (wording varies by device). If you see a signature conflict, uninstall the old build before installing the new one—uninstalling erases on-device app data, so back up first using in-app backup. If you previously installed a test build or an APK signed with an older key, uninstall it before installing the current signed release.

What are the system requirements?

Android 8.0 or newer. Current signed release v1.3.2, about 13.0 MB (see GitHub Releases).

Do I need the internet?

No internet needed for everyday use; entries and settings stay on your phone with no login or required backend.

How do I back up data?

In-app backup / restore (zip) and CSV export; backup files leave your device only when you share or save them.
