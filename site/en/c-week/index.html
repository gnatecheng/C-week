7-day learning path

The seven-day path matches the in-app curriculum; each day has a micro-lesson, quiz, and lab.

D1

Environment, files, and Hello World

Paths · bash · VS Code · first compile

Tell paths from workspaces, use the terminal for basic file ops, create .c in VS Code, compile with gcc, and use launch.json and breakpoints.

Lab: print Hello, Ada
D2

Types, variables, and I/O

Static typing · printf/scanf · no automatic cleanup

Declare int/double/char, read/write with printf/scanf, and understand overflow and stack variable lifetimes.

Lab: Celsius ↔ Fahrenheit
D3

Control flow and functions

if/for/while · prototypes · pass-by-value

Write functions with prototypes, understand pass-by-value in C, and see why swap needs pointers (setup for Day 4).

Lab: write is_prime
D4

Arrays, strings, pointers

Contiguous memory · addresses · '\0'

Draw pointer diagrams, use arrays and '\0' strings correctly, and avoid bounds and decay pitfalls.

Lab: reverse a string in place
D5

Structs, heap memory, files

struct · malloc/free · fopen

Define structs, allocate adjacency nodes on the heap, free correctly, and do basic file I/O.

Lab: highest score in a struct array
D6

Algorithms warm-up: sorting and BFS

Selection sort · adjacency list · grid/graph BFS

Understand selection sort, simulate an adjacency list with arrays, and complete BFS (queue + dist[]).

Lab: finish BFS relaxation
D7

Capstone: Dijkstra shortest paths

Non-negative weights · adjacency list · O(V²) teaching implementation

Complete the relaxation loop on your own, explain how it differs from BFS, and compile/run tests in VS Code.

Capstone: complete Dijkstra relaxation

FAQ

How do I install C Week?

Download the latest APK from GitHub Releases and install. Launcher name: “C Week” (C一周通).

Install tips (Android version, unknown sources, upgrades)

C Week requires Android 8.0 or newer. Download the signed release APK from GitHub Releases. On first install, Android may block APKs until you allow Install unknown apps for your browser or file manager (wording varies by device). If you see a signature conflict, uninstall the old build before installing the new one—uninstalling erases on-device progress and data, so export or back up first if the app offers it.

What are the system requirements?

Android 8.0 or newer; bundled lesson videos. Current signed release v1.5.1, about 15.6 MB (see GitHub Releases).

Do I need the internet?

Lessons, demo videos, and lab content ship in the install package; progress stays on your phone—learning works offline.

Does C Week compile C on the phone?

No. C Week uses offline simulated grading (multiple test cases, rule checks, and feedback). Partial credit shows a score; a lab counts complete only when all cases pass. You do not need gcc on the phone.

How does C Week work with VS Code on a computer?

Install VS Code and a C toolchain on your computer and follow along via the C Week open-source repo (Day 7 capstone and examples). The in-app About screen also links to the repo.
